A free church website template for parish and cathedral churches, with a liturgical calendar.

== Description ==

Canterbury is a free website theme for churches, part of a set of ten from ChurchCreation.

Fill in your church's name, address, telephone, email and giving link once under
Appearance > Customize > Church details, and they appear in the header, the
footer and the structured data together, so they cannot drift apart.

The typefaces are bundled and self-hosted. There are no external requests, no
tracking, and no account to sign up for. Dark mode is included and follows the
visitor's system setting.

== Installation ==

1. Appearance > Themes > Add New > Upload Theme.
2. Activate.
3. Appearance > Customize > Church details, and fill in your details.
4. Appearance > Menus, and assign a menu to the Primary and Footer locations.

== Frequently Asked Questions ==

= Where do I change the service times? =

Service times live in your page content, so edit the page in the block editor.
Only the details that repeat across every page — name, address, telephone,
email, giving link — are Customizer settings.

= Can I use this for a client? =

Yes. The theme is GPL and the design is free to use commercially.
